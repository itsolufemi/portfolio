ben's pizzeria

GH project repository JD project report

This project features a fully functional MySQL relational database built from the ground up to manage the backend operations of a fictional takeout and delivery business, "Ben's Pizzeria." Inspired by a data analytics brief, the repository demonstrates end-to-end database design, data engineering, and advanced SQL querying. The development process began by normalizing raw business requirements into a structured relational schema. This involved separating operational data into 10 distinct tables across Order Management, Inventory Tracking, and Staff Payroll. After defining the architecture and strict key constraints with an Entity-Relationship Diagram (ERD), mock data was generated and imported. This ingestion phase required hands-on data cleaning to resolve real-world deployment challenges, such as EOL character mismatches, data type inconsistencies, and primary key constraint violations within Navicat. Once the schema was populated and validated, the focus shifted to writing the complex SQL views necessary to feed a Business Intelligence dashboard. This included executing multi-table LEFT JOIN operations to unify order transactions, writing nested subqueries to track real-time ingredient depletion, and applying advanced chronological math (TIMEDIFF()) to accurately calculate daily staff payroll. Ultimately, this project transforms a conceptual business scenario into a structured, optimized, and query-ready database environment that is perfectly prepped for front-end BI visualization.
