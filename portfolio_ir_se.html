tate gallery collection search engine

This project was undertaken as a collaborative group effort by Me (Olufemi Davies-Davies) and Rohan Burman as part of the MSc Artificial Intelligence program at Queen Mary University of London for the Information Retrieval module. Driven by the curriculum's requirement to design, implement, and validate a bespoke search application from scratch, the team engineered and delivered the Tate Gallery AI Search System; a dual-path hybrid retrieval engine built over a corpus of digitized artwork records. To satisfy the first assignment, the team produced a technical report featuring an extensive literature review of foundational retrieval frameworks ranging from classic probabilistic models and structured fielded extensions to deep dense passage retrieval methods alongside a justified architectural roadmap for their system. For the final assignment, the contributors translated this design into a fully functional software ecosystem, submitting a modular Python codebase, summarizing presentation slides, a methodology video, and an interactive live demonstration video navigating real-world search scenarios.

The core deliverable features a hybrid pipeline that merges sparse lexical matching with dense semantic recall to efficiently resolve vocabulary mismatch. The sparse pathway applies heavy term-weighting across metadata fields like title, artist, and medium to ensure near-perfect precision for exact known-item lookups. Concurrently, the dense pathway captures deep contextual meaning by splitting unstructured data into overlapping chunks and calculating exact mathematical similarity against query vectors. These distinct scores are unified using Reciprocal Rank Fusion, which is enhanced by intent-aware re-ranking multipliers that favor dominant artist surnames, prioritize primary artistic mediums, and filter out archival junk records.

Beyond the retrieval orchestrator, the group delivered an automated data ingestion pipeline that downloads, cleans, and structures remote gallery files. Users can interact with the engine via an advanced Graphical User Interface containing pagination, artwork thumbnails, and dynamic matching explanations, or through a streamlined Command Line Interface. Both interfaces support system utility commands that hook directly into an automated unit testing suite and a sophisticated evaluation framework. This framework benchmarks the engine over a domain-specific set of fifty queries, confirming a rapid sub-50 millisecond operational response time alongside standard academic performance metrics including Mean Reciprocal Rank, Normalized Discounted Cumulative Gain, and overall retrieval success rates.
