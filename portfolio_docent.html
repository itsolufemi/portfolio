docent ai

JD project journal

Docent is a conversational audio guide designed for art galleries. I've always loved experiencing art in person — the colours more vivid, the scale more commanding — and I wanted to create something that deepens that connection. So I built Docent: a web-based audio guide that uses AI to bring artworks to life through storytelling. It improves on the stale version of audio guides by providing interactivity; users can talk to the application and ask questions, like they would with a human guide.

The initial version is a React and Node.js web application powered by OpenAI’s API. However, because of mobile browser restrictions on autoplay, the users would have to press a button to hear every response, which detracted from the user experience. I am now developing a mobile application using React Native (Expo), with a real-time WebSocket connection to OpenAI’s streaming API for low-latency audio playback.

Languages: JavaScript, Node.js, React, React Native (Expo), HTML, CSS

APIs/Services: OpenAI Chat API, Whisper & Google Speech-to-Text (STT), OpenAI TTS

Cloud: AWS S3 for audio storage & Puppeteer for web scraping
